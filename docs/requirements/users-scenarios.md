# 用户与使用场景

## 1. 目标用户
- **核心用户**：希望长期与 AI 进行深度交流、追踪成长与计划执行的人群。
- **扩展用户**：重视学习、目标管理、信息整合的知识工作者。

## 2. 用户画像（示例）
1. 个人成长者：有学习计划与自我管理诉求，希望有教练式监督与反馈。
2. 高效管理者：关注外部信息变化，需要主动提醒与整合建议。

## 3. 核心场景
### 3.1 记忆驱动对话
用户与 MOSS 多轮对话，系统根据长期记忆自动选择关键上下文（如近期目标、重要事件、健康/学习状态）进行增强。

### 3.2 主动提醒与对话
当外部世界发生变化（订阅信息、市场变化、天气、个人日程异常）或计划到期时，MOSS 主动联系用户并提供建议。

### 3.3 成长教练对话
系统识别出用户的计划、目标或困惑，自动形成结构化反馈与复盘建议，持续跟进成长轨迹。

### 3.4 未来扩展场景
多模态感知接入（语音、摄像头、穿戴设备等）后，根据实时状态开展更具情境感的互动。
