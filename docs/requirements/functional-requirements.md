# 功能需求（分模块）

## 1. 对话与记忆系统
### 1.1 基础对话
- 支持文本/语音输入（语音为可选扩展）。
- 对话具备跨会话上下文，基于用户长期档案进行记忆引用。

### 1.2 记忆管理
- 记忆类型：个人档案、目标计划、偏好、关键事件、长期习惯。
- 记忆操作：新增、更新、遗忘/降权、人工纠错。
- 记忆检索：按时间、主题、计划、情绪等标签化检索。

## 2. 上下文构建与决策
- 自动生成对话上下文（Context Builder）。
- 上下文来源：长期记忆、短期对话、当日状态、外部信息。
- 可解释性：向用户说明「为什么引用这部分记忆」。

## 3. 主动对话与提醒
- 事件触发：计划到期、异常行为、外部世界变化。
- 主动发起规则可配置（频率、时间段、主题优先级）。
- 用户可控制主动对话开关与提醒等级。

## 4. 计划与成长教练
- 从对话中识别计划/目标/困惑并结构化存档。
- 提供教练式反馈：阶段性目标、行动建议、复盘提醒。
- 长期跟踪：目标完成率、偏差分析、复盘总结。

## 5. 个人档案与偏好管理
- 用户画像：基础信息、兴趣、学习风格、价值观偏好。
- 可视化管理：用户可查看并编辑画像与记忆。

## 6. 外部信息与工具集成
- 信息订阅：新闻、行业动态、项目状态。
- 工具集成：日历、待办、笔记、邮件、IM 通知。
- 插件机制：可扩展第三方能力。

## 7. 权限与安全
- 本地/云端数据加密存储。
- 访问控制与数据审计。
- 多设备登录与同步。

## 8. 未来扩展能力（接口预留）
- 多模态感知接入（语音、图像、传感器）。
- 运动控制接口（仅定义协议，不做执行实现）。
