# 风险、伪需求与建议优化

## 1. 潜在伪需求/高风险需求
- **过度拟人化**：用户希望其“像人一样”主动聊天，但过度拟人化可能造成误解或依赖，需要明确系统定位与边界。
- **无限记忆**：长期记忆无限增长可能导致噪声和不准确，需设计记忆衰减机制与人工纠错能力。
- **高风险决策**：教练能力不应替代专业建议，需设置明确的免责声明与引导。

## 2. 风险点
- **隐私与信任**：用户敏感信息收集与使用必须透明。
- **主动打扰**：主动对话频率过高会造成用户反感。
- **上下文污染**：错误记忆影响输出质量。

## 3. 优化建议
- 引入「记忆可信度」和「可审查记忆库」机制。
- 主动对话分层：紧急提醒、日常建议、轻度问候。
- 用户可一键「临时静默」与「只接收重要提醒」。
