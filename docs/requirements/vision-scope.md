# 产品愿景与范围

## 1. 产品愿景
构建一个具备「长期记忆、主动沟通、成长教练能力」的个人 AI 主助理（MOSS），以**用户个人信息与长期目标**为上下文核心，提供持续性、可解释、可控的智能支持，最终可扩展到多模态感知与实体执行。

## 2. 项目目标（可度量）
- **持续性记忆**：支持跨会话的个人信息记忆与检索，满足长期对话与计划管理需求。
- **主动沟通**：基于事件触发、计划到期、外部信息变化等维度，主动联系用户并给出建议。
- **成长教练**：从对话中抽取计划与意图，提供结构化反馈、复盘、建议与鼓励。
- **可扩展能力**：支持未来接入多模态感知设备、外部服务与执行器。

## 3. 范围边界
### 3.1 范围内
- 个人信息与目标管理
- 长期记忆与上下文管理
- 主动对话与提醒
- 计划/任务/学习路径管理
- 教练与复盘功能
- 可扩展架构与插件能力

### 3.2 范围外（当前阶段不做）
- 大规模社会化关系链推荐
- 代替用户进行高风险决策（金融、医疗、法律等）
- 复杂机器人运动控制（仅做接口预留）

## 4. 版本策略
不是 MVP，而是生产级完整功能体系。可基于里程碑拆分交付，但功能设计时以终态完整性为优先。
